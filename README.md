# Biscuit the Hood Hound × Juiced

A free 3D browser game (three.js). You play Biscuit, a Jack Russell in shades,
running missions around the hood to win Cookie's heart. Originally built for
Vibe Jam 2026, now rebranded as a Juiced brand game.

Live: https://hoodhound.site/

## Change the brand settings

Everything brand-related lives in **`juiced-config.js`**:

| Setting | What it does |
| --- | --- |
| `shopUrl` | Where **SHOP JUICED** / **SHOP THE FIT** go. Empty = link to socials. |
| `socialUrl`, `handle` | Juiced socials (start-screen logo, share card). |
| `discountCode`, `discountText` | Reward revealed on the win screen. **Create the code in your store first.** Set `discountCode: ''` to hide it. |
| `gameUrl`, `gameLink` | Printed on the share card / used in the share text. |

## Where Juiced shows up in the game

- Biscuit wears a black Juiced bandana from the start; the Dumpster Diving
  bonus unlocks an orange **limited drop** colorway.
- Juiced murals, tags and billboards around the map (`art/`).
- HUD **SHOP JUICED** button.
- Win screen: stats, discount code + copy, Shop the fit, Share my card
  (1080×1350 PNG, native share sheet on phones), Play again.
- Link previews (Open Graph / X card) use `art/og.jpg`.

## Run locally

Any static file server works:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/.

## Regenerate the art

The murals, tags, billboards, bandana prints, road texture and link preview
are generated by a script. Edit the `TEXT` dict at the top (slogan, handle,
drop text) and run:

```bash
pip install pillow
```

```bash
python3 tools/juiced_art.py
```

Source images it edits live in `tools/src/`; fonts (OFL) in `tools/fonts/`.

## Deploy

It's a static site: upload the whole folder (or connect this repo to
Netlify / Vercel / Cloudflare Pages / GitHub Pages with no build step).
The old `files/` mirror on the server is no longer needed. `tools/` doesn't
need to be deployed.

## Notes

- three.js r128 is vendored in `lib/` (no CDN dependency).
- `toxic_waste.glb` was truncated on the old server; the game uses its
  built-in procedural barrels instead.
- Before using the game commercially, make sure you have the rights to the
  music (`Top_Dog.mp3`, `soundtrack.mp3`) and the AI-generated 3D models.
